Thử thách web này cho ta các files mã nguồn, pipeline hoạt động của thử thách. Mục tiêu lần này là kiểm thử White-box testing dựa trên thư mục có kiến trúc web MVC trên ứng dụng Node.js, ta có:

- routes: Khai báo toàn bộ các endpoints của ứng dụng web
- middleware: Kiểm tra đăng nhập, phân quyền và lọc requests trước khi cho qua
- controllers: Nhận dữ liệu từ users, gửi lên routes, xử lý logic rồi gọi tới services
- services: Xử lý nghiệp vụ và tương tác với tài nguyên hệ thống
- views: Chưa các file `.ejs` để hiển thị dữ liệu ra màn hình.

Sau khi đọc `/controllers/pageController.js` thì có thấy sự xuất hiện của bot, ghé thăm URL, tiếp tục đọc các file trong routes để xác định được endpoint mà bot có chức năng visit thì phát hiện ra endpoint có method **POST** `/report`. Đây là 1 endpoint cho phép viết ghi chú cũng như truyền vào 1 đường dẫn URL để report.

Khi đọc tiếp `/controllers/apiController.js` thì có thấy có một tính năng tại endpoint `/api/fetch` với method **POST** sẽ tiến hành tải file về và giải nén rồi mới validate lại. Tuy ứng dụng có chức năng kiểm tra lại sau khi giải nén, tuy nhiên nếu file được giải nén thoát ra ngoài thư mục `extractDir`, hàm validate không quét tới và file độc hại sẽ tồn tại vĩnh viễn. Dù vậy, endpoint này chỉ có method **POST** và cũng không thể truy cập bởi user bình thường không có role, vì vậy ta hướng tới việc lợi dụng cơ chế visit của bot để giúp ta tải lên file độc hại.

Đọc file bot.js, biết được bot được cấp role: Warden, tuy nhiên không login trực tiếp qua /enter như user mà đăng nhập bằng cách sinh jwt token rồi gắn cookie. Ý tưởng tổng quát của bài sẽ là sử dụng /report truyền vào 1 server tunnle do ta host, trên server sẽ có file độc hại và 1 file index.html để bot tự động truy cập `/api/fetch` và tải file `/exploit.tar`, server download về, giải nén và ghi đè lên file `enter.ejs`.

Sử dụng công cụ cloudflared, tạo 1 quick tunnel bằng `./cloudflared-linux-amd64 tunnel --url http://localhost:8000` và tạo một web server tạm bằng `python3 -m http.server 8000`.

Ý tưởng ban đầu là tạo 1 file nén .tar chứa các ký tự dot và slash để lùi file vừa giải nén ra thư mục gốc rồi ghi đè vào `/app/views/enter.ejs`, tuy nhiên thư viện download mới của Node.js đã có cơ chế chạy ngầm để lọc sạch dữ liệu, vì vậy ta chuyển qua sử dụng `Tar Symlink`.

Dùng script để đóng gói file exploir.tar với 1 bản ghi để tạo một liên kết ảo với thuộc tính **SYMTYPE**, trỏ trực tiếp đến /app/views/enter.ejs. Bản ghi thứ hai cũng có cùng tên với liên kết mềm ở trên nhưng chứa nội dung mã độc ejs.

Thư viện đọc bản ghi thứ 1 và tạo ra một liên kết mềm (Symlink) tên là link_to_enter bên trong thư mục giải nén tạm.
