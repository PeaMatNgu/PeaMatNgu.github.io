> This write-up documents work completed in an authorized lab environment. Flags, password hashes, and recovered passwords are intentionally omitted.

## Overview

Orion is a Linux machine that combines a vulnerable Craft CMS deployment with credential reuse and an unsafe local telnet service. Initial access comes from remote code execution in Craft CMS. Application configuration then reveals database access, and a crackable application password is reused for SSH. Finally, a telnet authentication bypass provides root access.

The attack path is:

1. Enumerate the HTTP service and identify Craft CMS 5.6.16.
2. Exploit CVE-2025-32432 to obtain code execution as the web-service account.
3. Read the Craft environment configuration and query the application database.
4. Recover the application user's password and reuse it for SSH.
5. Abuse the local GNU Inetutils telnet service to bypass authentication as root.

## Enumeration

The initial scan found SSH on port 22 and HTTP on port 80.

```bash
nmap -sC -sV -p- orion.htb
```

![Nmap scan showing SSH and HTTP on Orion](/assets/images/htb/orion/01-nmap.png)

After adding `orion.htb` to `/etc/hosts`, content discovery identified an `/admin` endpoint.

![Content discovery showing the admin endpoint](/assets/images/htb/orion/02-directory-enumeration.png)

The administration page disclosed Craft CMS 5.6.16.

![Craft CMS login page showing version 5.6.16](/assets/images/htb/orion/03-craftcms-version.png)

## Craft CMS remote code execution

The installed Craft CMS version was vulnerable to CVE-2025-32432. Craft uses Yii's dependency-injection and object-configuration mechanisms. A crafted request to an action route could influence object construction and instantiate a class with attacker-controlled callback behavior.

The exploitation flow required a valid session and CSRF context:

1. Request `/admin/login` and retain the Craft session cookie and CSRF token.
2. Use the vulnerable action route to make Craft process an attacker-controlled object configuration.
3. Place PHP code in the server-side session file.
4. Load that session file through a PHP manager component and trigger the stored code.

The callback initiated a reverse connection to the attacking host and provided a shell as the web-service account.

## Database access and SSH pivot

Craft's `.env` file exposed the local database connection parameters. With those credentials, the `users` table revealed a bcrypt password hash for the application user `adam`.

```sql
SELECT username, email, password FROM users;
```

The password was recoverable with a dictionary attack and had also been reused for the operating-system account. This allowed SSH access as `adam`. The hash and recovered plaintext are omitted from this article.

## Privilege escalation through telnet

Local service enumeration exposed telnet on `127.0.0.1:23`. Version inspection showed GNU Inetutils telnet 2.7.

```bash
netstat -tulnp
telnet --version
```

![GNU Inetutils telnet 2.7 on Orion](/assets/images/htb/orion/04-telnet-version.png)

The service was vulnerable to CVE-2026-24061. During autologin, telnet forwarded the local `USER` environment value to the server-side login program. Supplying a value that was interpreted as the login program's `-f root` option bypassed the normal password prompt:

```bash
USER="-f root" telnet -a 127.0.0.1
```

![Local telnet authentication bypass resulting in a root session](/assets/images/htb/orion/05-telnet-root-shell.png)

This produced a root session on the lab machine. Flag values are intentionally excluded.

## Lessons learned

- Administrative interfaces should not disclose precise component versions unnecessarily.
- Framework features that construct objects from request-controlled data need strict class allowlists.
- Environment files must be readable only by the service account that needs them.
- Password reuse turns one compromised application credential into a system compromise.
- Legacy remote-login services such as telnet should not be installed, even when bound only to localhost.
- Local services still form part of the privilege-escalation attack surface.
